# NotebookLM 딥리서치 무손실 수집 스킬 (워커 전사 표준)

## 입력
패킷이 지정한 현재 워크스페이스 내 프롬프트 파일(`ops/research/NotebookLM_*.md`). 파일 안에 다음 두 구역이 있다:
- `## SR-n` 블록: 딥리서치에 넣을 프롬프트 (코드 블록 안 텍스트를 그대로 붙여 넣는다)
- `## 후속 질문` 블록: 딥리서치가 끝난 뒤 순서대로 던질 질문 (`Q1`, `Q2` …)

## 절차
1. 브라우저에서 이미 열려 있는 NotebookLM 탭을 쓴다. 로그인·계정 변경·결제·공유 설정은 건드리지 않는다. 열려 있지 않거나 로그인이 필요하면 멈추고 보고한다.
2. 패킷이 지정한 노트북을 연다 (없으면 패킷 지시대로 새 노트북을 만든다).
3. `SR` 블록마다 딥리서치(Deep Research)를 시작한다. 끝날 때까지 기다린다 (진행 표시가 사라지고 보고서가 나올 때까지, 2분 간격으로 확인, 블록당 최대 30분).
4. 보고서가 나오면 **노트북 소스로 가져오기(Import)**를 누른다. 그다음 소스 목록에서 그 보고서를 열어 **본문 전체(표·수치·출처 목록 포함)를 처음부터 끝까지 그대로 복사**해 둔다.
   - 주의: `"보고서 생성 완료, 소스 N개"` 같은 요약으로 대신하는 것을 엄격히 금지한다 (원문 누락 절대 금지).
5. 모든 `SR`이 끝나면 채팅에 `## 후속 질문`을 하나씩 넣는다. 답이 끝까지 나온 뒤 다음 질문을 넣는다. 답 본문을 그대로 복사해 둔다 (인용 번호 포함).
6. 마지막으로 채팅에 `"지금까지의 딥리서치 보고서와 질문·답변을 빠짐없이 하나의 마크다운 문서로 정리해 주세요. 요약하지 말고 원문 수치와 출처를 유지하세요."`를 넣고 답을 복사한다.
7. 패킷이 지정한 현재 워크스페이스 내 출력 경로(`ops/research/notebooklm/` 아래)에 md 파일 하나로 저장한다. 구성:
   - `# 제목, 실행 시각, 노트북 이름`
   - `## 1. 딥리서치 보고서` (SR별 원문 전체 그대로)
   - `## 2. 후속 질문과 답변` (Q·A 원문 전체 그대로)
   - `## 3. NotebookLM 통합 정리` (6단계 답 원문)
   - `## 4. 실행 기록` (각 단계 시작·끝 시각, 실패·재시도, 잘린 답 여부)
8. 단기/대기 태스크이므로 불필요한 코디네이터 알림 방지를 위해 Heartbeat는 20분 이상 경과 시에만 전송하고, 완료 즉시 `worker_done`으로 보고한다.

## 절대 규칙
- 원문을 요약·의역하지 않는다. 복사가 잘리면 `"[잘림]"`으로 표시한다.
- 미공개 원고(`*/manuscripts/*`, 전자책 원고 본문), SSOT, `.env`·비밀키 파일을 NotebookLM에 올리지 않는다. 프롬프트 파일의 공개 질의 텍스트만 넣는다.
- **현재 워크스페이스 폴더 밖에 파일을 읽거나 쓰지 않는다** (Antigravity 확인 창 멈춤 방지).
- 딥리서치가 실패하거나 한도에 걸리면 그 사실을 `## 4. 실행 기록`에 적고, 남은 단계는 할 수 있는 만큼 진행한다.
