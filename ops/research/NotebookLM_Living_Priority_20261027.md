# NotebookLM 딥리서치 프롬프트: JE-Desk 라이프스타일 최우선 구현 과제 (스마트에디터 ONE 리치 퍼블리셔 및 실시간 링크 세이프가드)

> 용도: 관련 전문가 5인(알고리즘, 제휴마케터, 카피라이터, 데이터 엔지니어, AX 아키텍트) 검토 결과 도출된 최우선 구현 과제인 '네이버 스마트에디터 ONE 원클릭 리치 퍼블리셔' 및 '실시간 제휴 링크 세이프가드'의 기술 규격과 최적 아키텍처를 심층 수집한다.

## SR-1. 네이버 스마트에디터 ONE(SE One) 클립보드 리치 HTML 렌더링 규격 및 인라인 스타일 최적화

```
네이버 블로그의 스마트에디터 ONE(SmartEditor ONE) 웹 에디터에 마크다운 및 리치 HTML 콘텐츠를 클립보드로 붙여넣을 때, 서식(폰트 크기, 볼드, 글상자, 인용구, 구분선)이 깨지지 않고 네이버 순수 컴포넌트처럼 완벽히 렌더링되도록 하는 '인라인 클립보드 컴파일러' 사양을 심층 분석해 주십시오.

1. 스마트에디터 ONE 클립보드 붙여넣기(Paste Event) 처리 메커니즘:
   - 외부 HTML을 붙여넣을 때 네이버 에디터 내부의 DOM Sanitizer가 허용하거나 필터링하는 HTML 태그(h2, h3, p, blockquote, table, div 등) 및 인라인 스타일(style="...") 속성 허용 범위.
   - 인용구(버라인, 따옴표형) 및 글상자(배경색, 둥근 모서리, 여백)를 브라우저 복사-붙여넣기만으로 스마트에디터 고유 스타일과 100% 동일하게 인식시키는 CSS 인라인 규격.

2. 3단 카드뉴스 이미지 및 캡션의 인라인 배치 구조:
   - 본문 중간 1단(Before), 2단(Install), 3단(After) 카드뉴스가 스마트에디터 ONE의 사진+캡션 레이아웃으로 부드럽게 안착되도록 하는 마크다운/HTML 변환 공식.
   - 모바일 네이버 앱 및 PC 화면에서 반응형으로 100% 가독성을 유지하는 이미지-텍스트 간격 표준.

3. 위 내용을 "에디터 컴포넌트 | 허용 태그 및 인라인 스타일 | 네이버 에디터 자동 매핑 결과 | 주의사항" 표로 정리해 주십시오.
```

## SR-2. 옴니 제휴 링크 실시간 유효성/품절 감시 및 자동 대체(Failover) 세이프가드 아키텍처

```
오늘의집, 쿠팡, 올리브영 등 5대 제휴 플랫폼을 복합 운용할 때, 특정 상품이 품절되거나 링크가 만료되었을 때 트래픽 손실을 0%로 방어하는 '실시간 제휴 링크 세이프가드 & 스마트 스위처' 아키텍처를 심층 조사해 주십시오.

1. 제휴 링크 헬스체크 및 실시간 상태 감시 메커니즘:
   - 오늘의집 및 쿠팡 상품 URL의 HTTP 상태 코드(200 OK vs 404/302 리다이렉트) 및 HTML 응답 내 '품절/일시품절/판매중지' 텍스트를 감지하는 초경량 Zero-Dependency 검증 기법.
   - 1인 사업자가 서버 비용 없이 로컬 또는 정적 페이지에서 즉시 실행할 수 있는 자동 링크 스위칭 원리.

2. C-Rank 페널티 제로의 안전한 링크 배치 기법:
   - 본문 최하단 텍스트 박스 vs 첫 번째 댓글 상단 고정 방식의 클릭률(CTR) 및 알고리즘 안전성 실측 비교.
   - 공정거래위원회 심사지침을 준수하는 표준 텍스트 대가성 표기 형식.

3. 위 내용을 "플랫폼 | 품절 감지 시그널 | 대체(Failover) 우선순위 | 안전 배치 권장안" 표로 정리해 주십시오.
```
