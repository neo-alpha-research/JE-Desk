## SR-1. 네이버 블로그 스마트블록/DIA+ 최적화 및 C-Rank 어뷰징·유사문서·유사이미지 필터 회피 공학

```
네이버 블로그의 스마트블록(Smart Block) 및 DIA+(Deep Intent Analysis Plus) 랭킹 알고리즘에서 상위 노출을 확보하고, 저품질(C-Rank 하락, 누락, 어뷰징 제재)을 100% 방어하기 위한 리빙/살림 리뷰 포스팅 구조와 이미지 처리 기술을 심층 분석해 주십시오.

1. 스마트블록 및 DIA+ 상위 노출 본문 구조 (1,200~1,500자 규격):
   - DIA+ 알고리즘이 가산점을 부여하는 '실제 경험 기반 문서'의 핵심 속성(직접 겪은 불편 ➔ 구매 배경 ➔ 디테일 실사용 장단점 ➔ 꿀팁/비교 ➔ 종합 평가)과 문단 구성비.
   - 키워드 반복 과다(어뷰징) 판정을 피하면서 형태소 단위 자연어 검색(인텐트 매칭)에 걸려들게 하는 본문 키워드 배치 밀도(주요 키워드 3~5회 분산 배치) 및 LSI(잠재의미색인) 연관어 활용법.
   - 1,200~1,500자 최적 분량 내에서 체류 시간(Avg Time on Page)을 2분 30초 이상 끌어올리는 소제목(H2, H3), 인용구, 글상자 템플릿 표준.

2. C-Rank 저품질 및 제휴마케팅 외부 아웃링크 페널티 회피:
   - 본문에 쿠팡파트너스/외부 단축 URL을 직접 삽입할 때 발생하는 네이버 알고리즘의 상업성 문서 감점 원리와 이를 우회하는 안전한 링크 배치 기법(본문 최하단 배치, 텍스트 하이퍼링크 분산, 댓글 고정 링크 전략, 또는 네이버 지도/스토어팜 우회 브릿지).
   - 공정거래위원회 추천보증 심사지침에 따른 대가성 문구(공정위 배너/문구) 표기 위치 및 텍스트 렌더링 방식(이미지 배너 vs 텍스트 폰트)이 검색 노출에 미치는 영향.

3. 유사 이미지 필터 우회 및 EXIF 메타데이터 세탁·카드뉴스 래핑:
   - 상세페이지/스톡 캡처 이미지를 네이버 스마트렌즈 및 유사 이미지 판독 AI가 '고유 창작 이미지'로 인식하도록 변환하는 디지털 전처리 파이프라인.
   - EXIF 메타데이터 완전 삭제 및 카메라 기종(iPhone 15 Pro, Galaxy S24) 가상 태깅 기술.
   - 이미지 픽셀 변조 기법: 미세 크롭(2~3%), 미세 각도 회전(0.5도), 가우시안 노이즈(0.5%), 색온도 1~2% 변조, 캔버스 배경 래핑(배경 프레임 추가 및 카드뉴스 텍스트 박스 합성)의 FFmpeg/Pillow 구현 사양.

4. 위 내용을 "알고리즘 요소 | 감점/제재 요인 | 엔지니어링 방어 규격 | 실제 노출 가산점 효과" 표로 정리해 주십시오.
```

## SR-2. 쿠팡파트너스 & 토스 쉐어링크 고수익 소싱 매트릭스 및 트래픽 전환율(CTR/CR) 역학

```
리빙, 주방, 정리, 생활용품 카테고리에서 쿠팡파트너스 및 토스 쉐어링크(Toss Sharelink)를 활용한 N잡 자동화 시, 실질적인 구매전환율(Conversion Rate)과 순익을 극대화하는 아이템 소싱 기준과 데이터 분석 공식을 심층 조사해 주십시오.

1. 고수익·고전환 꿀템 선정 4대 기준 (소싱 매트릭스):
   - 가격대별 전환 저항선: 1만 원~3만 원대(충동구매 가능 영역), 3만 원~7만 원대(실용적 가성비 영역), 10만 원 이상(고관여 영역)의 전환율 비교.
   - 검색량 대비 상품 수(골든 키워드): 네이버 데이터랩 및 아이템스카우트 기준 월간 검색수 5,000~30,000회이면서 블로그 발행량 비율이 낮은 틈새 살림 꿀템 키워드 패턴.
   - 재구매율 및 시즌성: 4계절 상시템(실리콘 주방도구, 압축봉, 틈새수납함, 밀폐용기 등)과 시즌템(환절기 청소, 제습/가습, 미세먼지)의 소싱 배분 비율.

2. 토스 쉐어링크 vs 쿠팡파트너스 비교 분석:
   - 토스 쉐어링크의 수익 구조(클릭당 보상 vs 결제 수수료), 지급 주기, 유입 타깃층(모바일 간편결제 친화적 2040) 특성.
   - 쿠팡파트너스의 24시간 쿠키 세션 룰 및 장바구니 간접 전환(Halo Effect)을 노리는 '미끼 상품(Low-ticket hook)' 설계 전략.
   - 플랫폼별 단축 URL 차단 현황 및 리다이렉션 브릿지(개인 도메인 리다이렉트, 노션/인스타 브릿지) 필요성.

3. 클릭률(CTR)과 구매전환율(CR) 극대화 카피 및 CTA 공식:
   - 단순 "구매하기 링크" 대비 클릭률을 3배 이상 올리는 텍스트 앵커(예: "현재 최저가 할인 확인", "품절 전 로켓배송 재고 조회", "내돈내산 3개월 비교 후기").

4. 위 내용을 "카테고리/아이템군 | 권장 가격대 | 예상 CTR (%) | 예상 CR (%) | 소싱 추천 지표" 표로 체계화해 주십시오.
```

## SR-3. 스레드(Threads) 바이럴 퍼널 카피라이팅 및 아웃링크 페널티 회피 브릿지 설계

```
메타의 스레드(Threads) 알고리즘을 활용하여 리빙/살림 꿀템 콘텐츠를 바이럴시키고, 계정 품질 저하나 도달 제한(Shadowban/Reach Penalty) 없이 외부 구매 링크로 유입시키는 '스레드 4-Beat 퍼널'을 심층 분석해 주십시오.

1. 스레드 알고리즘과 외부 링크(아웃링크) 도달 패널티의 실체:
   - 본문에 외부 URL(쿠팡, 토스 등)을 포함할 때 발생하는 노출량(Reach) 급감 메커니즘.
   - '첫 댓글 링크 배치', '프로필 링크트리(리틀리, 포스타입, 노션) 유도', '스레드 본문 이미지 내 텍스트 QR/도메인 안내'의 도달률 보존 효과 비교.

2. 4-Beat 고전환 카피라이팅 공식 (살림/리빙 특화):
   - 1-Beat [스크롤 스토퍼 훅]: 주부/자취생의 일상적 고통·비효율을 정밀 타격하는 첫 문장 (예: "다이소에서 5만 원 버리고 결국 정착한 주방템 3가지").
   - 2-Beat [공감 및 결핍 심화]: 누구나 겪는 현실적 짜증과 실패 경험 서술 (감정선 동기화).
   - 3-Beat [반전 및 해결책 제시]: 해당 아이템을 통해 삶의 질이 수직 상승한 팩트와 디테일(비포/애프터 비교).
   - 4-Beat [자연스러운 CTA & 첫댓글 유도]: 강요하지 않고 정보를 원하는 사람에게만 링크 위치를 안내하는 마무리 문구 (예: "좌표 물어보시는 분들이 많아서 첫 댓글에 최저가 링크 남겨둘게요").

3. 스레드 인터랙션(저장, 공유, 댓글) 부스팅 트리거:
   - 알고리즘이 가산점을 주는 '북마크(저장) 유도형 카루셀/체크리스트' 작성 기법.
   - 댓글 반응을 유도하여 추천 탭(For You)에 강제 부스팅시키는 논쟁/질문형 클로징.

4. 위 내용을 "단계 (Beat) | 핵심 목표 | 카피 패턴 및 예시 | 심리적 트리거 | 알고리즘 반영 지표" 표로 정리해 주십시오.
```

## SR-4. 상용 툴(대한AI팩토리 DAF, 샷포스팅) 아키텍처 벤치마크 및 로컬 '네이버 임시저장' 준자동 적재 파이프라인

```
시중의 블로그 자동화 상용 툴(대한AI팩토리 DAF, 샷포스팅 등)의 구동 아키텍처와 한계를 분석하고, 1인 사업자가 계정 정지 위험 없이 안전하게 운영할 수 있는 '로컬 네이버 블로그 임시저장(Draft) 준자동화 파이프라인'을 심층 분석해 주십시오.

1. 상용 툴(DAF, 샷포스팅 등)의 기능 및 기술적 한계:
   - 상용 툴들의 글 생성 엔진(GPT-4o/Claude API 기반 템플릿 치환)과 이미지 자동 수집 방식.
   - 완전 자동 포스팅(API 또는 셀레니움/플레이라이트로 직접 '발행' 버튼 클릭) 시 발생하는 네이버의 캡차(CAPTCHA), IP 추적, 비정상 세션 감지 및 대량 저품질 제재 리스크.

2. '완전 자동 발행' vs '임시저장 후 수동 검수 발행(Semi-Auto)' 비교:
   - 안전성과 계정 장수(C-Rank 누적) 측면에서 '임시저장 준자동화'가 갖는 절대적 우위.
   - 네이버 스마트에디터 ONE의 내부 API(`https://blog.naver.com/api/...`) 또는 로컬 헤드리스 브라우저를 활용한 임시저장(Draft Save) 규격.
   - 마크다운(Markdown) 문서를 네이버 스마트에디터 호환 JSON/HTML 블록 구조(제목, 본문, 소제목, 인용구, 이미지 컴포넌트)로 변환하는 파싱 기술.

3. 로컬 1인 AX 데스크 솔루션 아키텍처 사양:
   - 입력: 쿠팡/토스 상품명 또는 URL
   - 공정 1: 상품 스펙·리뷰 크롤링 및 LSI 키워드 추출 (0-토큰 정규식/HTML 파서)
   - 공정 2: DIA+ 규격 1,200자 리뷰 본문 생성 (LLM 프롬프트)
   - 공정 3: 제품 이미지 다운로드 ➔ EXIF 세탁 ➔ 캔버스 카드뉴스 래핑 (Pillow)
   - 공정 4: 네이버 블로그 임시저장함 자동 적재 (로컬 브라우저 세션 활용) + 스레드 4-Beat 원고 텍스트 클립보드 복사
   - 최종 작업: 사용자가 네이버 블로그 앱/웹에서 임시저장 글 열어 '10초 검수 후 발행' 클릭 (100% 안전 보장).

4. 위 내용을 "파이프라인 단계 | 사용 기술/도구 | 자동화율 (%) | 소요 시간 | 계정 안전도" 표로 정리해 주십시오.
```
